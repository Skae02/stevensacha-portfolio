01 · sobre mí

Sobre mí

Soy Ingeniero de Software con sólidos conocimientos en desarrollo de aplicaciones Full Stack para entornos web y móviles. Cuento con experiencia en desarrollo Frontend con React y React Native, así como en desarrollo Backend con FastAPI (Python), integrando servicios mediante API REST.

He participado en la incorporación de soluciones basadas en Inteligencia Artificial mediante las API de OpenAI, y uso herramientas como Claude Code para el análisis de código, la resolución de problemas, la refactorización y la implementación de funcionalidades.

Tengo experiencia en despliegue y administración de aplicaciones con Docker y plataformas en la nube como Google Cloud y Microsoft Azure, además de gestión de proyectos y control de versiones con Git, GitHub y Azure DevOps, aplicando prácticas de desarrollo continuo y colaborativo.

  • Full Stack web y móvil

    React, Next.js y React Native en el frontend; FastAPI y API REST en el backend.

  • Desarrollo asistido por IA

    Integración de la API de OpenAI y uso de Claude Code en el ciclo de desarrollo.

  • Cloud y DevOps

    Docker, Google Cloud, Microsoft Azure y Azure DevOps.
